# Analisador de Números - Projeto JavaScript

Este projeto consiste em um "Analisador de Números" desenvolvido com HTML, CSS e JavaScript. O objetivo é permitir ao usuário adicionar números entre 1 e 100 a uma lista e, ao finalizar, exibir informações como:

<ul>
<li>Quantidade total de números inseridos</li>
<li>Soma dos números</li>
<li>Média dos valores</li>
<li>Maior e menor número da lista</li>
</ul>
A interface foi projetada para ser simples e interativa, com uma validação para garantir que os números sejam válidos e não se repitam. O layout é responsivo, adaptando-se a diferentes tamanhos de tela.

Tecnologias utilizadas:
<ul>
<li>HTML</li>
<li>CSS</li>
<li>JavaScript</li>
</ul>

Este projeto foi criado para praticar a manipulação de arrays e interações dinâmicas no navegador com JavaScript.

O projeto foi desenvolvido assistindo às aulas do Gustavo Guanabara no curso "Curso em Vídeo", oferecido gratuitamente no YouTube.
